# Simple Tally Counter

キーボード操作で高速カウントできる数量集計ツール。

## 機能

- 件数ごとの枚数をキーボードでカウント
- 1〜0キーで1〜10件目の枚数を+1、Shift+キーで-1
- テンキー対応
- 合計値（件数×枚数）のリアルタイム計算
- 枚数合計・合算値合計の自動表示
- 行数可変（デフォルト15行）

## 使い方

1. `index.html` をブラウザで開く
2. キーボードの1〜0キーで該当行の枚数をカウント
3. Shift+キーで枚数を減らす
4. 11行目以降は直接入力

## 技術スタック

- HTML / CSS / JavaScript（バニラ）
- 外部ライブラリなし

## ファイル構成

```
SimpleTallyCounter/
├── index.html   # 全機能を含む単一ファイル
└── README.md
```

## 設計意図

- **キーボードオンリー操作**: マウス不要で高速入力
- **シンプル構成**: 外部依存なし、単一HTMLファイルで完結
- **意図的なキャッシュ不使用**: リロードでリセット（業務用途での誤操作防止）
